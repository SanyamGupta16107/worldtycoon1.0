# 🌐 WORLD TYCOON 1.0
### Global Strategy Simulation & Sovereign Macro Asset Trading

WORLD TYCOON is a high-production browser-based board game combining classic property-trading mechanics with dynamic real-time macro-economic simulation, industry specializations, global crisis shocks, live auctions, and online peer-to-peer multiplayer.

---

## 🎮 Game Features

- **🌐 Online Multiplayer via WebRTC Room Codes**: Host or join live matches using 6-character room codes (`WT-XXXXXX`) across any browser with zero server setup required.
- **👥 Pass & Play Local Hotseat**: Support for 2 to 4 human commanders on one shared screen.
- **🤖 Adaptive AI Competitors**: Play against NEXUS-AI, VALKYRIE-AI, and QUANTUM-AI with distinct risk personalities (Aggressive, Balanced, Conservative).
- **🏛️ Global Auction Arena**: Space 16 features live multi-party bidding wars for unowned properties or liquidated assets with interactive countdown timers.
- **🔥 High-Risk Global Stock Exchange**: Random speculative trading windows with extreme returns (+200% to +500% Moonshots or -50% to -100% Liquidity Meltdowns).
- **🏙️ 3-Set Development Protocol**: Upgrade properties to Level 1, Level 2, or Level 3 Mega-Complexes once you secure at least 3 holdings in the same world region.
- **🏦 Mortgaging & Liquidation**: Unlock instant 50% cash liquidity by mortgaging holdings, unmortgage to restore rent collections, or liquidate to the Central Bank for 70% market valuation.
- **📊 Real-Time SVG Intelligence Desk**: Dynamic market index charts, world region radar scans, and regional crisis news.
- **🎵 Procedural Audio Engine**: Web Audio API sound synthesizer with zero external audio asset dependencies.

---

## 🛠️ Tech Stack

- **Framework**: React 18 & TypeScript
- **Styling**: Tailwind CSS & Glassmorphism UI
- **Animations**: Framer Motion / Motion
- **Networking**: PeerJS (WebRTC DataChannels) + BroadcastChannel fallback
- **Audio**: Procedural Web Audio API Synthesizer
- **Bundler**: Vite 6

## 🚀 Running Locally

1. Clone repository:
   ```bash
   git clone https://github.com/SanyamGupta16107/WorldTycoon-1.0.git
   cd WorldTycoon-1.0
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start local development server:
   ```bash
   npm run dev
   ```
4. Build production bundle:
   ```bash
   npm run build
   ```
